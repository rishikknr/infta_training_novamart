# NovaMart synthetic retail data and Snowflake SQL

Synthetic datasets and versioned SQL definitions for TRACE lineage verification.

SQL under `sql_quries/` includes 22 baseline ingestion statements, 22 staging views, three curated views and six analytics views. Credential values in setup scripts are placeholders. Configure credentials privately before any intentional provider execution. TRACE reads these definitions as metadata; registering lineage does not execute them.
